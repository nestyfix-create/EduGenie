# EduGenie 🎓

## AI Learning Assistant

EduGenie is an AI-powered learning assistant developed using Python, Flask, HTML, CSS, JavaScript, and Google Gemini API.

## Features

- Ask questions and get AI-generated answers
- Summarize text
- Generate quizzes
- Explain topics in simple language
- Student-friendly interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API

## How to Run

1. Install Python.
2. Install the required packages.
3. Add your Gemini API key to `.env`.
4. Run the Flask application using:

```bash
python app.py
